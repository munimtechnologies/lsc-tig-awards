# LSC technology grants, 2014 and 2015: what LSC still shows, checked

The Legal Services Corporation (LSC) announced its 2014 Technology Initiative Grant
(TIG) round on 17 October 2014 and its 2015 round on 4 November 2015. For 2014 the full
list is a two-page PDF that is still on lsc.gov, one row per grantee, with LSC's own
total printed on it. For 2015 LSC never printed a list: the page it linked as the full
list held one summary paragraph (the Internet Archive has 25 captures of it, 6 November
2015 to 20 September 2019, all without a list), and its address now opens the press
release. This page sums the 2014 list, checks both rounds against the releases still on
lsc.gov and against LSC's own counts, and checks LSC's cumulative "since 2000" figures
across the two releases. It extends [tig-2016-2017.md](tig-2016-2017.md) and
[tig-history.md](tig-history.md) back two more rounds, to the start of the releases
LSC keeps online.

Data: `data/tig_2014_2015.json` (CC BY 4.0). Code: `tig_2014_2015.py` (Apache-2.0).
Read from the raw text of each document (the PDF through two text extractors and its
page images) and hand-checked; the hand sums are pinned in `test_tig_2014_2015.py`.

    python tig_2014_2015.py              # each round's rows, sums and stated totals
    python tig_2014_2015.py --sources    # each release's amounts, parts and group totals
    python tig_2014_2015.py --headlines  # LSC's statements and cumulative figures
    python tig_2014_2015.py --summary    # headline figures as JSON

## The lists

| Year | List | Grantee rows | Organizations | States | Territories | Grants (at least) | Sum of the amounts | LSC's stated total | Difference | Grantees with an amount on lsc.gov today |
|---|---|---|---|---|---|---|---|---|---|---|
| 2014 | PDF on lsc.gov | 30 | 30 | 21 | 1 | 34 | $3,467,978 | $3,467,978 | $0 | 11 |
| 2015 | none (releases only) | 7 | 7 | 7 | 0 | 8 | $1,214,048 | - | - | 7 |

- **2014: the list adds up exactly.** The PDF's 30 rows sum to $3,467,978, the "TOTAL
  FUNDING" it prints, which is $32,022 short of $3.5 million and so fits "nearly $3.5
  million". The copy on lsc.gov today and the Internet Archive's copy of 27 September
  2015 are the same file byte for byte (SHA-256
  `1685c827118fbb7d04f04461b0b3326df43b2d37fb29e46ee4ffa5a6964760c2`); the PDF was made
  on 17 October 2014, the day of the announcement. Its 22 jurisdictions (21 states and
  Puerto Rico) match its "22 STATES & TERRITORIES".
- **2014: the PDF has one row per grantee, so "38 PROJECTS" cannot be checked from it.**
  The local releases break three rows into parts (Bay Area Legal Aid two, Pine Tree Legal
  Assistance two, Legal Assistance of Western New York three), so the 30 rows hold at
  least 34 projects. The main release's descriptions number further projects within a
  row ("1) ... 2) ...") but give no amounts for them.
- **2015: only 7 of the 30 grantees are known.** LSC's releases name amounts for seven
  grantees, $1,214,048 in all: five in the TIG releases, and two (LAF in Illinois and
  Blue Ridge Legal Services in Virginia) only in the 2015 Pro Bono Innovation Fund
  release. That leaves at least $2,985,952 of "more than $4.2 million", across 23
  grantees, with no public amount. Northwest Justice Project's $505,660 is two grants,
  so the known grants are 8 of the 36 LSC counts.

## LSC's statements against the lists

| Year | Source | LSC says | Counts that miss the list | Not checkable | Dollar figure fits the sum |
|---|---|---|---|---|---|
| 2014 | PDF list | 38 projects, 22 states and territories, exactly $3,467,978 | none | projects | yes |
| 2014 | release | nearly $3,500,000 | none | none | yes |
| 2014 | release | 38 projects | none | projects | - |
| 2014 | local releases | 38 organizations, nearly $3,500,000 | organizations | none | yes |
| 2015 | list page (archived) | 30 organizations | - | organizations | - |
| 2015 | release | more than $4,200,000 | - | none | - |
| 2015 | release | 30 organizations | - | organizations | - |
| 2015 | per-grantee release | 30 organizations, more than $4,200,000 | - | organizations | - |
| 2015 | PBIF per-grantee release | 36 grants | - | grants | - |

- **2014: "38 recipients" is the project count, not the grantee count.** Each of the
  six local releases ends "one of 38 recipients of 2014 LSC-TIG funding", but the list
  has 30 grantees; 38 is the PDF's and the main release's number of projects.
- **2015: "30 organizations" and "36 grants" are consistent with each other**, since
  one grantee alone holds two grants, but with no list neither can be checked. The Pro
  Bono Innovation Fund release calls 2015 the program's "16th year", which fits a start
  in 2000.

## LSC's cumulative figures

| | Grants | Dollars |
|---|---|---|
| Cumulative stated in the 2014 release | 570 | more than $46,000,000 |
| 2014 round, as LSC states it | 38 | $3,467,978 |
| 2015 round, as LSC states it | 36 | more than $4,200,000 |
| Sum of those three | 644 | more than $53,667,978 |
| Cumulative stated in the 2015 release | 644 | more than $53,000,000 |

The 2014 release, published the day the 2014 round was announced, says the program
"has funded 570 technology projects totaling more than $46 million" since 2000. The
2015 release says "644 grants for a total of more than $53 million". The counts fit
exactly, 570 + 38 + 36 = 644, but only if the 570 excludes the 2014 round announced in
the same release. On that reading the 2015 figure also confirms 36 grants for 2015 (the
number in the Pro Bono Innovation Fund release, not the 30 organizations in the TIG
release) and 38 for 2014. The dollars are consistent too: $46 million plus the two
rounds is at least $53,667,978, which is "more than $53 million". (LSC's January 2015
TIG conference release says "Through 2014, LSC has funded more than 570 TIG projects,
totaling more than $46 million"; the arithmetic works only if that "through 2014" does
not include the 2014 round.)

## Limits

- The 2015 round is incomplete by construction: 7 of 30 grantees. No LSC page, release
  or archived copy found lists the other 23, and LSC's "TIG Awards 2000-2020" Airtable
  view loads by script and could not be read as text.
- "Grants (at least)" counts a row with no stated grant count as one grant. The 2014
  rows hold at least 34 grants; LSC says 38 projects.
- Grants are as announced. Nothing here shows what LSC actually paid.
- States are read from each grantee's name and, for the 2014 PDF, its state heading.
- The cumulative check assumes LSC's 2014 and 2015 "since 2000" figures count the same
  thing ("projects" in 2014, "grants" in 2015).
